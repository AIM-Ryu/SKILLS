SETUP GUIDE

入れ方（5分）

  1. Claude Code を入れる
    まだの方は先にインストールしてください。Windowsの方は Git for Windows（Git Bash）も一緒に入ります。
  2. スキルを置く
    ダウンロードしたフォルダの中身（aim- で始まる10個のフォルダ）を ~/.claude/skills/ にまるごとコピーします。
  3. Claude Code を再起動する
    起動中に入れても読み込まれません。一度終了してから開き直してください。
  4. 動くか確かめる
    Claude Code に「営業文を書きたい」と話しかけてみてください。セットアップが始まれば成功です。
